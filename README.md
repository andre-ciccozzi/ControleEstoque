# ControleEstoque - AGS Solution

**Seu sistema completo de gerenciamento de estoque!**

O ControleEstoque da AGS Solution é um software completo para gerenciar o estoque da sua empresa de forma eficiente e organizada. Com ele, você terá total controle sobre seus produtos, usuários, acessos e relatórios do inventário.

## Funcionalidades:

- Cadastro e login de usuários
- Controle de acesso por perfil de usuário e administrador
- Painel administrativo com gestão de usuários
- Cadastro de itens com patrimônio e sem patrimônio
- Visualização do estoque em telas organizadas
- Exportação dos dados para Excel
- Banco com fallback para SQLite
- Resumo geral do estoque para apoio na tomada de decisão

- Otimização do processo de compras
- Melhora na tomada de decisões
- Aumento da lucratividade
- Organização da área administrativa e operacional
